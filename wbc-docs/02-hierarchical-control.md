# 02 · 分级控制（Hierarchical Control）

> 目标：解释“多任务冲突时谁让谁”，以及零空间、严格优先级 QP、加权 QP 的实现差别。
> 读完后你应该能判断：你的固定基座 18 DoF 系统到底需不需要 HQP。

---

## 1. 为什么需要分级

WBC 通常要同时满足很多任务：

- 左右末端要跟踪抓取轨迹；
- 躯干要保持某个姿态；
- 关节要尽量靠近舒适 posture；
- 关节不能超限、力矩不能饱和；
- （浮动基）脚不能滑、CoM 要落在支撑多边形内。

这些任务**不可能同时精确满足**：自由度有限、任务互相冲突、约束会挤占空间。于是要回答：

> 冲突时，牺牲哪个任务？

两种答案：

1. **加权**：给每个任务一个权重，大家在一个 QP 里“商量”，高权重任务误差小，但不保证严格满足。
2. **分级（严格优先级）**：任务排队，高优先级先满足，低优先级只能在高优先级留下的**零空间**里优化。高优先级永远不会被低优先级破坏。

“分级控制”通常指第 2 种。它是 WBC 里最常被提到、也最容易被过度使用的概念。

---

## 2. 优先级的语义

设任务按优先级从高到低为 `T1, T2, ..., Tk`。

严格优先级要求：

```text
T1 的解集合 S1
T2 在 S1 内找最优，得 S2 ⊆ S1
T3 在 S2 内找最优，得 S3 ⊆ S2
...
```

即：**低优先级不能恶化任何高优先级任务的（最优）代价**。

如果高优先级是硬约束（如关节限位、接触），低优先级必须在满足这些硬约束的前提下优化。

加权 QP 的语义是：

```text
min  w1*c1 + w2*c2 + ... 
```

它允许“用一点点 T1 的误差换很多 T2 的改善”，只要总代价下降。权重需要标定，且任务量纲不同（米 vs 弧度）时很难调。

## 3. 零空间投影（Null-Space Projection）

### 3.1 运动学零空间

对任务 1：

```text
xd1 = J1 qd
qd1 = J1^+ xd1                 # 最小范数解
N1  = I - J1^+ J1              # 零空间投影
```

`N1` 把任意速度投影到“不改变任务 1 输出”的子空间。对任务 2：

```text
qd2 = qd1 + N1 J2^+ (xd2 - J2 qd1)
N2  = N1 (I - J2^+ J2)
```

递归下去：

```text
qd = J1^+ xd1
   + N1 J2^+ (xd2 - J2 J1^+ xd1)
   + N2 J3^+ (xd3 - J3 (...))
   + ...
```

优点：解析、快、可解释。
缺点：

- 只处理等式任务，不等式（限位、摩擦锥）很难塞进去；
- 伪逆在奇异位形附近数值不稳定；
- 多任务、多约束时表达式迅速膨胀。

### 3.2 动力学一致的零空间

上面的 `J^+` 是欧氏伪逆。对动力学系统，更合理的是 **M 加权伪逆**（dynamically consistent pseudo-inverse）：

```text
J^# = M^{-1} J^T (J M^{-1} J^T)^{-1}
N   = I - J^# J
```

它保证零空间运动不产生任务方向的加速度，且与惯量分布一致。操作空间控制（Operational Space Control）就是基于它：

```text
Lambda = (J M^{-1} J^T)^{-1}          # 任务空间惯量
F      = Lambda (xdd* - Jdot qd) + ...
tau    = J^T F + N^T tau_0            # tau_0 是低优先级/姿态力矩
```

其中 `N^T tau_0` 把低优先级力矩投影到零空间。

优点：物理意义清晰，适合“主任务 + 姿态”这种结构。
缺点：仍然难处理不等式和多级任务；接触/摩擦锥要另外处理。

## 4. 加速度级分层 QP（HQP）

现代 WBC 更常用**加速度级分层 QP**，因为它能统一处理等式和不等式。

### 4.1 两级形式

第 1 级（最高优先级）：

```text
min_{qdd}  || J1 qdd - b1 ||²
s.t.       C1 qdd ≤ d1
```

解出 `qdd1*`，以及第 1 级的最优代价 `c1*`。

第 2 级：

```text
min_{qdd}  || J2 qdd - b2 ||²
s.t.       || J1 qdd - b1 ||² ≤ c1*        (不恶化第 1 级)
           C1 qdd ≤ d1
           C2 qdd ≤ d2
```

如果第 1 级只有等式 `J1 qdd = b1`，第 2 级可以直接把它作为等式约束；如果第 1 级有不等式，则用上面的“代价不恶化”约束，或把第 1 级的有效约束（active set）固定为等式。

### 4.2 多级

```text
for i = 1..k:
    min_{qdd} || Ji qdd - bi ||²
    s.t.  所有高优先级任务的最优性约束/有效约束
          所有高优先级不等式
          本级不等式
```

实现方式：

1. **级联 QP**：逐级求解，把上一级的解/有效约束传给下一级。简单，但每级都要解一次 QP。
2. **零空间递归**：解析地构造高优先级零空间，在零空间里解低优先级。适合等式任务。
3. **专用 HQP 求解器**：把分层结构直接编码进求解器（TSID、mc_rtc 的 Tasks 库）。

### 4.3 带不等式的严格优先级

严格优先级 + 不等式时，要小心：

- 高优先级不等式可能让低优先级问题**不可行**；
- 高优先级等式可能和低优先级不等式冲突；
- 需要给低优先级任务加 slack，或允许“软优先级”。

工程做法：

- 最高层（安全、关节限位、接触）永远是硬约束；
- 中间层（任务）用等式/软约束；
- 最低层（posture）用软约束 + slack；
- 如果 QP 不可行，按优先级从低到高放松。

### 4.4 一个两级 HQP 的伪代码

```python
# Level 1: 末端任务（高优先级）
H1 = J1.T @ W1 @ J1 + eps * I
g1 = -J1.T @ W1 @ b1
x1 = solve_qp(H1, g1, C1, d1)          # 等式/不等式

# 把 level-1 的有效约束作为 level-2 的等式
A_eq2 = active_constraints_of_level1
b_eq2 = ...

# Level 2: posture（低优先级）
H2 = J2.T @ W2 @ J2 + eps * I
g2 = -J2.T @ W2 @ b2
x2 = solve_qp(H2, g2, [A_eq2; C2], [b_eq2; d2])
```

真实 HQP 还要保证 level-2 不恶化 level-1 的最优代价；上面的“有效约束固定”在等式任务下是等价的，在不等式任务下是近似。

## 5. 加权 QP vs 分层 QP

| | 加权 QP | 分层 QP（HQP） |
|---|---|---|
| 形式 | 单个 QP | 多个 QP / 专用求解器 |
| 优先级 | 软（权重） | 严格 |
| 调参 | 权重量纲敏感，难调 | 只需排优先级 |
| 计算量 | 小 | 大（2–5 倍） |
| 可行性 | 一个 QP，较容易 | 每级都可能不可行 |
| 可解释性 | 中 | 高 |
| 适用 | 固定基座、任务不冲突、原型 | 人形/多接触、安全关键、任务冲突明显 |

**建议**：

- 你的固定基座 18 DoF：先用**加权 QP**。任务只有末端、躯干、posture，冲突不剧烈，权重够用。
- 如果出现“末端精度和躯干姿态明显打架”“posture 把末端拉走”“需要严格安全层”，再上 HQP。
- 以后上浮动基/多接触，接触和限位必须是硬约束，任务才需要严格分级。

## 6. 典型优先级栈

### 6.1 浮动基人形（参考）

```text
0. 硬约束：关节位置/速度/力矩限位、自碰撞、接触不滑动、摩擦锥
1. 平衡：CoM / centroidal momentum
2. 支撑脚/摆动脚轨迹
3. 末端（手）位姿
4. 躯干姿态
5. posture / 关节舒适度
```

### 6.2 你的固定基座轮式人形

```text
0. 硬约束：关节位置/速度/加速度/力矩限位
1. 左右末端 6D 位姿（操作精度）
2. 躯干 3D 姿态（保持直立/前倾）
3. posture（冗余分解、避免奇异）
```

如果躯干姿态只是“尽量保持”，放第 2 层；如果躯干姿态影响相机/平衡，提到第 1 层或与末端同级。

## 7. 数值与工程问题

1. **任务量纲**：位置（m）和姿态（rad）权重不可直接比较；按“期望误差量级”归一化。
2. **奇异位形**：`J` 降秩，伪逆爆炸；用阻尼伪逆 `J^T (J J^T + λ² I)^{-1}` 或 QP 正则项。
3. **有效约束抖动**：HQP 的 active set 在切换时会跳变；加滞环/平滑。
4. **不可行**：给低优先级任务加 slack，或按优先级放松；不要静默返回错误解。
5. **实时性**：HQP 的 3 级 QP 在 18 DoF 上仍然很小，Python 可以到 200–500 Hz；C++ 可以更高。
6. **一致性**：所有任务/约束用同一 `qdd` 变量、同一 `q/qd` 状态、同一时间戳。
7. **初始化**：warm start 上一周期的解，能显著降低求解时间。
8. **验证**：每级解出来后，检查高优先级任务的残差是否真的没变差。

---

## 8. 一页总结

```text
分级控制 = 任务按优先级排队，低优先级只能在高优先级零空间里优化。

三种实现：
1. 零空间投影（解析，等式任务，快）
2. 加速度级 HQP（QP 级联，可处理不等式，现代 WBC 主流）
3. 加权 QP（单 QP，软优先级，简单）

你的固定基座场景：
  加权 QP 足够；需要严格安全/任务冲突时再上 HQP。
  硬约束永远是关节限位/力矩/速度；任务按 末端 > 躯干 > posture 排。
```
